水中格闘2 Prototype v0.8
起動: index.html

新キャラ：セラフィエルさん
コンセプト：ミカエルの上位系 / 高攻撃・低防御

技:
・上＋パンチ　セラフィックアッパー
・前＋キック　セラフィックキック
・後ろ＋パンチ　セラフィックショット
・下→前→後ろ＋キック　セラフィックサイクロン
・下→前＋パンチ　セラフィックレイ（独自技）

セラフィックショット：
白金色の高速弾。シャボンガードで反射可能。

セラフィックレイ：
約0.3秒の細い予告線の後、水中を横切る太い白金の光。
通常の飛び道具ではないため反射不可。
シャボンガード中なら大幅にダメージ軽減。

能力：
攻撃力かなり高め / 防御低め / 移動やや速め。
隠しキャラ想定ですが、試作中は選択画面から使用可能。
