水中格闘2 Prototype v1.4
起動：index.html

ストーリーモード全面更新
・前作「カエル大戦！？」後の平和な池から、水中格闘大会開催へ。
・大会参加者から主人公側5人をランダム選出。
・ベルゼブブ／カワズが主人公側に選ばれた場合は後半戦へ回る。
・サマエルは反対ブロックを勝ち上がり、最終日の決勝へ。
・1日目：1～3回戦 → リヴァイア乱入事件。
・2日目：4～5回戦 → アスモデウス乱入事件。
・最終日：サマエルとの決勝。
・優勝後、大会主催者セラフィエルとのSPECIAL MATCH。
・専用エンディング追加。

v1.4.1 修正
・サンダーチャージ／ライトニングダッシュの進行方向を発動時に固定。
  相手を通り過ぎて向きが反転しても、高速で往復せずそのまま画面端方向へ抜ける。
・ムーンサルトキックは残像だけでなくサリエル本体を高速縦回転。
  多段ヒット判定はそのまま。

v1.5 キャラ選択UI
・画面上部にフリー対戦／ストーリー／操作練習／全キャラ対戦を常時表示。
・難易度、SE、フリー対戦相手も上部にコンパクト表示。
・キャラ一覧だけが縦スクロールする構成へ変更。
・カーソル／選択時の技表示は維持。
・スマホでは4つのモードを横一列で常時表示。
・全キャラ対戦モードを追加。選択キャラ以外と連戦し、ボスクラスを後半、セラフィエルを最後に配置。

v1.5.1 サリエル調整
・ムーンサルトキックの上昇量を大幅に低下。
・前進量も少し抑え、相手の近くで高速回転し続ける性格へ。
・途中ヒットのノックバックを弱くし、スロー状態の相手へ多段ヒットしやすく調整。
・最終段だけは吹き飛ばしを残す。
