水中格闘2 Prototype v1.4
起動：index.html

ストーリーモード全面更新
・前作「カエル大戦！？」後の平和な池から、水中格闘大会開催へ。
・大会参加者から主人公側5人をランダム選出。
・ベルゼブブ／カワズが主人公側に選ばれた場合は後半戦へ回る。
・サマエルは反対ブロックを勝ち上がり、最終日の決勝へ。
・1日目：1～3回戦 → リヴァイア乱入事件。
・2日目：4～5回戦 → アスモデウス乱入事件。
・最終日：サマエルとの決勝。
・優勝後、大会主催者セラフィエルとのSPECIAL MATCH。
・専用エンディング追加。

v1.4.1 修正
・サンダーチャージ／ライトニングダッシュの進行方向を発動時に固定。
  相手を通り過ぎて向きが反転しても、高速で往復せずそのまま画面端方向へ抜ける。
・ムーンサルトキックは残像だけでなくサリエル本体を高速縦回転。
  多段ヒット判定はそのまま。

v1.5 キャラ選択UI
・画面上部にフリー対戦／ストーリー／操作練習／全キャラ対戦を常時表示。
・難易度、SE、フリー対戦相手も上部にコンパクト表示。
・キャラ一覧だけが縦スクロールする構成へ変更。
・カーソル／選択時の技表示は維持。
・スマホでは4つのモードを横一列で常時表示。
・全キャラ対戦モードを追加。選択キャラ以外と連戦し、ボスクラスを後半、セラフィエルを最後に配置。

v1.5.1 サリエル調整
・ムーンサルトキックの上昇量を大幅に低下。
・前進量も少し抑え、相手の近くで高速回転し続ける性格へ。
・途中ヒットのノックバックを弱くし、スロー状態の相手へ多段ヒットしやすく調整。
・最終段だけは吹き飛ばしを残す。

v1.5.2 キャラ選択画面
・スマホ横持ちは左：モード／フリー対戦相手／難易度／SE、右：キャラ選択。
・右側キャラ一覧だけスクロール。
・フリー対戦の相手選択も左パネル内へ移動。
・キャラの技表示は従来通りカーソル／選択時に表示。
・縦持ちでは自動的に上下配置へ戻る。

v1.5.3 ストーリー演出
・オープニング／大会途中の会話では、決勝相手と大会主催者の固有名を伏せる。
・決勝前は「？？？」、主催者は「大会主催者」と表記。
・キャラ選択画面のSTORY予告からも両名の名前を削除。
・実際に対戦へ入った時点ではキャラクター名を表示。

v1.5.4 オープニング微調整
・「格闘大会開こうよ」を「格闘大会を開いてもらえないか、頼みにいこうよ」へ変更。
・大会主催者が会話に参加していたように見えない流れへ修正。
・誰に頼みに行ったのかは伏せたまま。

v1.6 ポーズ機能
・通常戦闘中、画面上部中央に「ポーズ」ボタンを追加。
・ポーズ中はゲーム進行、CPU、飛び道具、状態異常タイマーなどを完全停止。
・使用中キャラの技表をポーズ画面へ表示。
・「戦闘に戻る」で再開。
・PCではEscキーでもポーズ／再開可能。
・操作練習や各ミニゲームではポーズボタンを非表示。

v1.6.1 キャラ選択レイアウト修正
・スマホ横持ちで、左約1/3をモード・設定・フリー対戦相手。
・右約2/3をキャラ選択専用スクロール領域として強制配置。
・右側キャラ一覧を画面幅いっぱいまで使うよう max-width 制限を解除。
・横持ちスマホではキャラ一覧3列、広い画面では4列。

v1.6.2 キャラ選択画面のレイアウト競合を修正
・旧CSSの #selectScreen.screen.active { display:flex } が新しい左右分割を上書きしていた問題を修正。
・横持ち時は左約30%をモード／設定、右約70%をキャラ選択として固定。
・キャラ一覧は右側の幅だけで3列表示し、右側だけ縦スクロール。
・キャラカードの古い横スクロール／固定幅指定を右ペイン内では完全に上書き。
・技表はカードを押し広げず、選択カード上に浮かせて表示。

v1.6.3 キャラ選択画面をHTMLから再構築
・モードメニューの閉じタグ欠落で、右キャラペインまで左側へ入っていた構造バグを修正。
・左パネルと右パネルを完全な兄弟要素として再構成。
・横持ち：左31%モード、右69%キャラ一覧。
・縦持ち：上42%モード、下58%キャラ一覧。
・ストーリー／全キャラ対戦／操作練習／フリー対戦の4ボタンが独立して重ならない。
・キャラ名は横書き固定。カードからはみ出さないよう再調整。

v1.6.4 キャラ選択微調整
・カワズさんを外の池キャラ（リヴァイアさん／アスモデウスさん）より前へ移動。
・リヴァイアさんとアスモデウスさんの選択カードに旧表示指定が混ざる問題を修正。
・外の池キャラの絵と名前をカード中央に収めるよう調整。

v1.7 進行・CPU調整
・リヴァイアさん／アスモデウスさん選択時はストーリーボタンを無効化。
・サマエルさん／セラフィエルさんはストーリークリアまでキャラ選択・フリー対戦相手一覧から非表示。
・ストーリークリア時に両キャラを永続アンロック（localStorage）。
・全キャラ対戦でも未クリア時はサマエル／セラフィエルを使用キャラ候補から除外。

CPU飛び道具ガード
・イージー：約26%
・ノーマル：約52%
・ハード：約78%
・上記はCPUがほぼ静止していて攻撃／必殺技をしていない時の反応率。
・移動中、攻撃中、必殺技中は飛び道具ガード抽選を行わず、そのまま被弾しやすい。
・ガード失敗後は短時間再抽選しないため、同じ弾を毎フレーム100%近くガードする挙動を廃止。

v1.7.1 キャラ選択カード表示調整
・カエル画像をカード左側に固定し、名前用の領域を右側に確保。
・名前の先頭文字が顔に隠れる問題を修正。
・横持ちの狭い画面では顔を少し縮小して名前との間隔を維持。

v1.7.2 修正
・モード選択が反応しなくなるJavaScript初期化順の不具合を修正。
  ストーリーボタンの参照前に refreshStoryAvailability() が呼ばれていたのが原因。
・カワズさんはアンロック後、リヴァイアさん／アスモデウスさんの直前へ挿入。
・既にDOM上にカワズさんがいる場合も外の池キャラより前へ並び直す。

v1.7.3 修正
・ストーリーで敗北した場合は勝ち上がらず、同じ相手と「再戦」。4敗目でGAME OVER。
・ラファエルCPUを距離戦型へ変更。近づかれたら逃げ、適正距離から4種の水圧カッターを中心に戦う。
・リヴァイア／アスモデウスの選択カードに累積していた旧CSSの疑似パーツを全廃し、素直な魚／ザリガニアイコン表示へ整理。

v1.8 水槽闘技場
・通常のフリー対戦／大会戦を水槽闘技場化。
・上部照明レール、ガラスの支柱、観客席シルエット、リング床、光の筋を追加。
・ストーリー1日目は青白い照明。
・2日目は少し紫寄りの照明。
・決勝／セラフィエル戦は金白の照明＋大型円形装飾で豪華な決勝水槽。
・リヴァイア／アスモデウス戦は外の池扱いのため闘技場描画なし。

v1.8.1 水槽闘技場ビジュアル調整
・通常大会水槽を大幅に明るく変更。
・透明度を上げ、濁り・深度による暗さを削除。
・水槽闘技場では草などの水草を完全撤去。
・ガラス越しに後方の観客席が薄く透けて見える構成へ変更。
・以前の時間経過で徐々に暗くなる背景処理を水槽闘技場では使用しない。
・1日目／2日目／決勝の違いは明るさではなく照明色だけで表現。
・決勝も暗転せず、金白の照明と装飾で豪華さを出す。
・リヴァイア／アスモデウス戦だけは従来の外の池背景。

v1.8.2 緊急修正
・v1.8.1で drawBackground() が存在しない stageThemeData() を呼んでいたため、
  描画ループが背景処理で停止し、闘技場・キャラが描画されない問題を修正。
・大会水槽は明るい透明水槽背景を維持。
・リヴァイア／アスモデウス戦のみ自然の池背景。

v1.8.3 水槽闘技場調整
・奥の水に複数の波状屈折ラインと縦方向の歪みを追加。
・観客を人型シルエットからカエル型シルエットへ変更。
・観客色は緑多め＋青・黄・紫・ピンクを混ぜたカラフル構成。
・画面下の大きな楕円リング線を削除。
・床は薄い水平反射だけ残す。

v1.8.4 水槽闘技場演出
・観客カエルの一部が両手を上げて盛り上がるように変更。
・片手を振る観客も追加。
・水槽手前に小さなレフリーカエルを追加。
・レフリーは左右にゆっくり移動し、時々片手を上げる。
・レフリーは背景演出のみで戦闘には干渉しない。

v1.8.5 調整
・キャラ選択カードの名前領域をさらに右へ拡張し、顔で先頭文字が隠れないよう修正。
・大会水槽を白寄りの薄いクリアブルーへ変更。
・水の屈折線、観客席背景、ガラス反射を薄くして透明感を強化。
・レフリーカエルを緑の肌＋白黒ストライプのレフリー服へ変更。
