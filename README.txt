新キャラ：コカビエルさん
配色：深い青紫＋シアン。

前＋パンチ：グラビティボール
・遅めの重力球。近くの相手を球へ引き寄せる。
・シャボンで反射可能。反射後は引力対象も元の撃ち手側へ切り替わる。

後ろ＋ガード：グラビティゾーン
・相手付近に重力場を設置。
・約0.42秒の予告後、約3秒間その地点へ相手を引き寄せる。

下＋パンチ：メテオレイン
・相手の発動時位置を中心に、画面上から5発の圧縮水塊を時間差で落とす。
・シャボンでは反射せず、大幅軽減して受け流す。

重力で相手の位置を動かし、次の攻撃につなぐ制圧型。

v1.1.1 調整

コカビエル

ジィハル

・サンダーチャージ命中後も突進速度を完全維持。
・命中時に自分を相手の反対側へ抜けさせ、接触で止まらないよう修正。
・ライトニングダッシュ／サンダーチャージ中は通常減速を受けず設定速度を維持。
